### Tool-call settings for B0 and B2 (eval plan Table 6)

Only the tool-call flags differ between the rows; every other server flag is the run's own (here the smoke command above). GRC-Agent reads tool calls only from the server's parsed `tool_calls`, never from the answer text.

| Setting | Server flags | Chat format (log) | Tool grammar in the log | Calls held to the schema | Server returns parsed `tool_calls` | Usable by GRC-Agent as is |
|---|---|---|---|---|---|---|
| B2: grammar-constrained tool calls | `--jinja (Jinja chat template, chat parsing on: the build's default)` | peg-native | yes | yes | yes | yes |
| B0 candidate: calls as the model writes them | `--jinja --skip-chat-parsing` | peg-native | yes | no | no | no |
| No Jinja | `--no-jinja` | n/a | n/a | n/a | no (3/3 tool requests refused: `tools param requires --jinja flag`) | no |
| B0 request-level candidate: tool_choice "none" + "parse_tool_calls": true (a llama.cpp request field) | `--jinja (the B2 server)` | peg-native (HTTP 200) | no | n/a | no | no: GRC-Agent sends tool_choice "auto" |

**Reading.** With `--jinja` (the default), llama.cpp b10333 compiles the request's tool schemas into a grammar and applies it once the model opens a tool call, so the server's default IS the B2 setting (grammar-constrained tool calls). No flag of this build gives parsed but unconstrained calls: the one setting without the tool grammar (`--skip-chat-parsing`) also leaves the calls unparsed in the text, `--no-jinja` refused the tool requests, and a request may not bring its own grammar together with tools (HTTP 400), and the request-level candidate (`tool_choice: "none"` + `parse_tool_calls: true`) gave no parsed calls that break the schema. An unconstrained B0 therefore needs harness work (an open decision for the team): llama-server with `--jinja --skip-chat-parsing` plus a parser in the harness that turns the model's own tool-call text into `tool_calls` (keeping malformed calls as malformed calls), or B0 is defined as the default server, in which case B0 and B2 are the same configuration.
