# Tier-A first set

Generated by `./gb tier-a sheet` (`grcbench.tier_a.spec_drafts`); the tasks are written by `./gb tier-a first-set` and checked by `./gb tier-a gates all`. Remaining-work plan step 6; eval plan §4.4, §5.4 and §13.

- **Built and gated:** 10 test and 12 dev tasks. Every task's start graph is a Tier-F graph of the same split, or File > New.
- **Specs only:** 20 test tasks (`items/tier_a/test_spec_drafts.jsonl`), to be built after the team's decision on the first set.
- **Status:** every task and spec was drafted by Claude (Anthropic) and is pending team review (`docs/checklists/tier_a_task_review.md`; sheet `handoff/review_sheets/tier_a_first_set.csv`).

## Notes for the reviewers

- Start graphs reuse Tier-F graphs of the same split (eval plan §13), so their functional signatures are already reserved from training. Tasks on the same Tier-F graph share its `cluster_id`, which the clustered statistics use.
- Each task records its disjointness from the training task specifications (t01-t25) in `disjointness`; the nearest spec is named.
- Some specs ask the team for a decision in `build_notes` (gba-test-24: build-and-save close to t13; gba-test-29: an unsafe-request refusal in Tier A).
