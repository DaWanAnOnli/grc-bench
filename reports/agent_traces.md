# Qoherent's agent traces (15-18 Oct) against GRC-Bench

Generated by `./gb traces` (`grcbench.contamination.agent_traces`). The traces are training data and are used in full for training; this report checks the benchmark against them (eval plan §6).

## 1. The data

- **Tier 1:** 1253 one-shot traces, 60 GNU Radio subcategories. Families: t1_addwire 443, t1_guard 98, t1_nmm 118, t1_retune 448, t1_topo 146.
- **Tier 2:** 600 two-turn traces. Families: t2_build 150, t2_correct 100, t2_query 100, t2_refine 150, t2_rewire 100.
- **Teacher:** deepseek-v4.1-flash, through GRC-Agent's own harness, on GNU Radio 3.10.9.2 (the benchmark pins 3.10.12).

## 2. Harness

Reference: Qoherent's SFT release (`grc-agent-sft-v0.1.0/grc-agent-sft-v0.1.0/sft_train.jsonl`), which the Tier-A conformance check uses.

- System prompt: every trace has the same prompt, identical to the reference apart from the session line and the active flowgraph's path.
- Tools: one tool set in every trace. Only in the traces: final_result (GRC-Agent's output tool, which the evaluation harness also offers). Only in the reference: none.
- `change_graph` schema: added /parameters/$defs/BlockAdd/additionalProperties; changed /parameters/$defs/BlockAdd/properties/params/anyOf; removed /parameters/$defs/BlockAdd/title; added /parameters/$defs/ParamUpdate/additionalProperties; added /parameters/$defs/ParamUpdate/properties/params/properties; removed /parameters/$defs/ParamUpdate/title ...
- `run_command` schema: changed /parameters/properties/timeout_seconds/description
